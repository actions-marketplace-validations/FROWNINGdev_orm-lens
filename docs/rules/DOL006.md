# DOL006 — Drop list() around a QuerySet in for-loop

**Default severity:** info · **Applicability:** suggestion · **Category:** queryset

Detects `for x in list(qs):` where `qs` could be a QuerySet. Iterating a normal QuerySet fills its result cache. Calling `list(qs)` also allocates a separate list of references to the same results. For chunked reads, use `.iterator()` without wrapping it in `list()`.

The "Drop list() and iterate directly" Quick Fix is a suggestion. Keep `list()` if the loop needs a snapshot, for example when deleting entries from a dictionary during iteration. A bare name or attribute may refer to any iterable.

## Bad

```python
for user in list(User.objects.filter(is_active=True)):
    send_digest(user)
```

## Good

```python
for user in User.objects.filter(is_active=True):
    send_digest(user)
```

## Suppress

```python
# orm-lens-disable-next-line DOL006
```

To turn the rule off for the workspace, add `{"djangoOrmLens.rules": {"DOL006": "off"}}` to `.vscode/settings.json`.
