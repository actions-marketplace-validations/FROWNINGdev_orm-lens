# DOL006 — Eliminare list() attorno a un QuerySet in un ciclo for

**Gravità predefinita:** info · **Applicabilità:** suggestion · **Categoria:** queryset

Rileva `for x in list(qs):` quando `qs` può essere un QuerySet. Iterare direttamente un QuerySet riempie la cache dei risultati. `list(qs)` crea anche una lista di riferimenti agli stessi risultati. Per leggere i dati in blocchi, usa `.iterator()` senza `list()`.

La Quick Fix "Drop list() and iterate directly" è un suggerimento. Mantieni `list()` se il ciclo richiede una copia, per esempio per eliminare voci da un dizionario durante l'iterazione.

## Non corretto

```python
for user in list(User.objects.filter(is_active=True)):
    send_digest(user)
```

## Corretto

```python
for user in User.objects.filter(is_active=True):
    send_digest(user)
```
