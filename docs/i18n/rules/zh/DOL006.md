# DOL006 — 去掉 for 循环中包裹 QuerySet 的 list()

**默认严重程度：** info · **适用性：** suggestion · **类别：** queryset

检测 `for x in list(qs):` 这种写法，其中 `qs` 可能是 QuerySet。遍历普通的 QuerySet 会填充它的结果缓存，而调用 `list(qs)` 还会另外分配一个列表，存放指向同一批结果的引用。如需分块读取，请使用 `.iterator()`，并且不要再用 `list()` 包裹它。

QuickFix（“Drop list() and iterate directly”）属于 suggestion。如果循环需要一份快照，例如在遍历过程中从字典里删除条目，请保留 `list()`。单独的名称或属性可能指向任何可迭代对象。

## 错误示例

```python
for user in list(User.objects.filter(is_active=True)):
    send_digest(user)
```

## 正确示例

```python
for user in User.objects.filter(is_active=True):
    send_digest(user)
```
