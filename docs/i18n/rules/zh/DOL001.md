# DOL001 — 优先使用 .exists()，而不是 .count() > 0

**默认严重程度：** info · **适用性：** safe · **类别：** queryset

检测把 `qs.count() > 0`（以及 `qs.count() >= 1`）用作存在性判断的写法。`.count()` 会让数据库执行 `SELECT COUNT(*)`，扫描或统计所有匹配的行；`.exists()` 则执行 `SELECT 1 ... LIMIT 1`，找到第一行就停止。在大表上，两者的差别相当于整张表与一行。改写前后语义完全相同，因此 QuickFix（“Rewrite to .exists()”）可以自动应用，也可以通过“Fix All”批量应用。

## 错误示例

```python
if Order.objects.filter(user=user).count() > 0:
    notify(user)
```

## 正确示例

```python
if Order.objects.filter(user=user).exists():
    notify(user)
```
