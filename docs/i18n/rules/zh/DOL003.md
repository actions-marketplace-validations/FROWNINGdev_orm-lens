# DOL003 — 优先使用 not .exists()，而不是 .first() is None

**默认严重程度：** info · **适用性：** safe · **类别：** queryset

检测把 `qs.first() is None` 用作判空条件的写法。`.first()` 会对 queryset 排序并取回完整的一行——所有列都会被反序列化为模型实例——而结果随后就被 `is None` 比较丢弃了。`.exists()` 只询问数据库是否存在这样一行。如果之后确实需要这个对象，请保留 `.first()` 并复用返回的实例；本规则针对的是取回的行被直接丢弃的情况。QuickFix（“Rewrite to not .exists()”）可以安全地自动应用。

## 错误示例

```python
if Subscription.objects.filter(user=user).first() is None:
    prompt_upgrade()
```

## 正确示例

```python
if not Subscription.objects.filter(user=user).exists():
    prompt_upgrade()
```
