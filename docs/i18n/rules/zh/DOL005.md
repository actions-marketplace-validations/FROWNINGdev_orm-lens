# DOL005 — 考虑用 Q(...) 代替 .filter().exclude() 链式调用

**默认严重程度：** hint · **适用性：** suggestion · **类别：** queryset

检测同一行中的 `.filter(...).exclude(...)` 链式调用。这两个调用通常可以合并为一个 `.filter(Q(...) & ~Q(...))`——用一个表达式写出完整的筛选条件，读者无需在脑中组合两个链式调用。两种写法本来都只会生成一条查询，因此这关乎可读性，而不是速度。本规则是提示（hint），而不是错误：在多值关系上（跨越 `ManyToManyField` 或反向外键时），`.exclude(...)` 与 `~Q(...)` **并不**等价——`.exclude()` 会排除*任意*关联行匹配的对象，而 `~Q` 是按连接后的每一行进行筛选。改写前请先仔细检查；本规则有意不提供 QuickFix。

## 错误示例

```python
posts = Post.objects.filter(published=True).exclude(author=request.user)
```

## 正确示例

```python
from django.db.models import Q

posts = Post.objects.filter(Q(published=True) & ~Q(author=request.user))
```
