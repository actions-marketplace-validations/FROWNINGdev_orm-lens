# DOL002 — 优先使用 not .exists()，而不是 .count() == 0

**默认严重程度：** info · **适用性：** safe · **类别：** queryset

检测用 `qs.count() == 0` 判断结果是否为空的写法。为了与零比较而统计所有匹配的行，比直接询问数据库是否至少存在一行要多做许多工作——`.exists()` 会被转换为 `SELECT 1 ... LIMIT 1`，不需要统计行数。改写前后语义完全相同，因此 QuickFix（“Rewrite to not .exists()”）可以自动应用，也可以通过“Fix All”批量应用。

## 错误示例

```python
if Order.objects.filter(user=user).count() == 0:
    show_empty_state()
```

## 正确示例

```python
if not Order.objects.filter(user=user).exists():
    show_empty_state()
```
