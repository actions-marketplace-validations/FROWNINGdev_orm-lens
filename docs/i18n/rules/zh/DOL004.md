# DOL004 — 优先使用 .exists()，而不是 .first() is not None

**默认严重程度：** info · **适用性：** safe · **类别：** queryset

检测把 `qs.first() is not None` 用作存在性判断的写法。与 DOL003 一样，这会取回一整行并将其实例化，却在与 `None` 比较之后就把它丢弃；`.exists()` 发出 `SELECT 1 ... LIMIT 1`，只传回判断结果。只有在之后还要使用返回的实例时，才应保留 `.first()`。QuickFix（“Rewrite to .exists()”）改写前后语义完全相同，可以安全地自动应用。

## 错误示例

```python
if Invite.objects.filter(email=email).first() is not None:
    raise AlreadyInvited
```

## 正确示例

```python
if Invite.objects.filter(email=email).exists():
    raise AlreadyInvited
```
