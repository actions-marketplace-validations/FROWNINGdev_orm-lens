# DOL006 — Bỏ `list()` bọc ngoài QuerySet trong vòng lặp for

**Mức độ mặc định:** info · **Khả năng áp dụng:** suggestion · **Danh mục:** queryset

Phát hiện `for x in list(qs):` khi `qs` có thể là QuerySet. Duyệt trực tiếp QuerySet sẽ lưu kết quả vào bộ nhớ đệm. `list(qs)` tạo thêm một danh sách tham chiếu đến cùng các kết quả. Để đọc dữ liệu theo từng phần, dùng `.iterator()` mà không bọc bằng `list()`.

Quick Fix “Drop list() and iterate directly” là một đề xuất. Hãy giữ `list()` nếu vòng lặp cần một bản chụp, chẳng hạn khi xóa mục khỏi từ điển trong lúc duyệt.

## Sai

```python
for user in list(User.objects.filter(is_active=True)):
    send_digest(user)
```

## Đúng

```python
for user in User.objects.filter(is_active=True):
    send_digest(user)
```
